社内イベント管理システム マニュアル

対象システム: スポーツ科学総合センター Events

最終更新: 2026年3月30日

1. システム概要

このシステムは、社内イベントの情報を一元管理・公開するための Web アプリケーションです。

画面 URL 対象
公開サイト index.html 全社員（閲覧のみ）
管理画面 admin/index.html 管理者（編集・公開）

データの流れ: 管理画面で編集 → GitHub に保存 → 公開サイトに自動反映

2. 公開サイトの使い方（一般ユーザー向け）

2-1. ホームビュー（カード一覧）

サイトを開くと、登録されているイベントがカード形式で一覧表示されます。

  • カードは 開催日が近い順 に並んでいます。
  • 各カードには 日程・カテゴリ・タイトル・開催場所・参加人数・担当者 が表示されます。
  • 「詳細を見る」 ボタンをクリックすると、イベントの詳細情報がポップアップで表示されます。
  • カードの 日付エリア をクリックすると、カレンダー画面のその日付に移動します。

2-2. カレンダービュー

上部ナビゲーションの 「カレンダー」 をクリックすると、ガントチャート形式でスケジュールを確認できます。

ボタン 表示内容
1日 選択した1日の詳細タイムライン
1週間 7日間のタイムライン
2週間 14日間のタイムライン
1ヶ月 カレンダー（デフォルト）
  • 「前へ」「次へ」 ボタン: 表示期間を移動
  • 今日の日付 は赤い縦線で表示されます。イベントバーをクリックすると詳細が表示されます。

2-3. イベントの申請

社員がイベントを申請したい場合は、ホーム画面の 「イベントを申請する」 ボタンから Microsoft Forms にアクセスしてください。

3. 管理画面の使い方（管理者向け）

管理画面（admin/index.html）を開くと、以下のパネルが表示されます。

  1. GitHub 接続設定 — データの読み込みと公開に必要
  2. リアルタイム同期（Firebase） — 複数管理者での共同編集（任意）
  3. イベント一覧 — イベントの追加・編集・削除
  4. 実施報告（承認待ち） — 閲覧サイトから送信された報告の確認
  5. 確認済み報告 — 承認済みの実施報告の管理

4. 初期設定（初回のみ）

4-1. GitHub アクセストークンの取得

  1. github.com に管理者アカウントでログインする。
  2. 右上のプロフィールアイコン → Settings をクリック。
  3. 左メニューの一番下 → Developer settings をクリック。
  4. Personal access tokens → Tokens (classic) をクリック。
  5. Generate new token → Generate new token (classic) をクリック。
  6. Note に AG Admin と入力し、任意の有効期限を設定。
  7. スコープ: repo にチェックを入れ、Generate token をクリック。
  8. 表示された ghp_ で始まるトークンをコピーする。

重要: トークンは一度しか表示されません。必ずコピーしてから画面を閉じてください。

4-2. GitHub 接続設定

  1. 管理画面の 「GitHub 接続設定」 パネルを開く。
  2. GitHubリポジトリのURL を入力欄に貼り付け、「自動設定」ボタンをクリック。
  3. アクセストークン を入力する（手順4-1で取得したもの）。
  4. 「設定を保存」 をクリックし、「接続してデータを読み込む」 をクリック。

5. イベントの追加・編集・削除

管理画面の「追加」ボタンからイベントフォームを開き登録します。一覧から「編集」「削除」も可能です。

注意: 削除は元に戻せません。誤って削除した場合は、GitHubのコミット履歴から復元できます。

6. 実施報告の確認と管理

公開サイトから送信された「実施報告」は、管理画面で確認および承認を行うことができます。

6-1. 実施報告の確認（承認）

  1. 管理画面の 「実施報告」 セクションに、未承認の報告が新着順で表示されます。
  2. 内容を確認し、問題なければ 「確認」 ボタンをクリックします。
  3. 報告は「実施報告」リストから消え、下部の 「確認済み報告」 に移動します。

6-2. 詳細の確認

  • 一覧の「詳細」ボタンを押すと、投稿された写真や本文などの全容をモーダルで確認できます。

6-3. 確認済み報告の管理

「確認済み報告」 セクションでは以下の操作が可能です。

  • 詳細: 再度内容を確認できます。
  • 未確認に戻す: 誤って承認した場合などに、元の未承認リスト（実施報告）に戻します。
  • 削除: 不要な報告をシステムから完全に削除します（※取り消しできません）。

7. 公開サイトへの反映手順

イベントの追加・編集・削除を行っただけでは、公開サイトには反映されません。以下の手順で反映してください。

  1. 変更が完了したら、画面右上の 「公開サイトに反映する」 ボタンをクリック。
  2. GitHub にデータが保存され、公開サイトに反映されます。

8. 複数管理者でのリアルタイム共同編集（Firebase）

Firebase を設定すると、複数の管理者が同時に管理画面を開いていても、リアルタイムで変更が同期されます。管理画面内の「リアルタイム同期」パネルから、Firebaseコンソールの firebaseConfig を貼り付けて接続してください。

10. よくある質問

Q. 「接続してデータを読み込む」を押してもイベントが表示されない
アクセストークンが正しいか確認してください。またトークンの有効期限が切れていないかも確認してください。
Q. 「公開サイトに反映する」を押してもサイトに反映されない
GitHub Pages のデプロイには数分かかる場合があります。しばらく待ってからページをリロードしてください。
Q. 複数人で同時に編集するとどうなる？
Firebase を接続していない場合、後から「公開サイトに反映する」をクリックした方のデータで上書きされます。同時編集には Firebase のリアルタイム同期の使用を推奨します。
